Destination: `OCKM-STUDIO/OCKM_GENERATOR`. Keep it **private** until Simon has tried
the native Mac preview and explicitly chooses to publish.

application bundles and dependency build caches are ignored by Git; attach a
Mac ZIP to a private preview release when distributing a build. Personal audio,
projects, settings and `.pi/` credentials remain excluded.
